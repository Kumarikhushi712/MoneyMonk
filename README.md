# MoneyMonk - Your Personal Finance Bestie!

## 🚀 What's This About? 

Yo! Tired of being broke? 😭 Can't track where your money goes? 
MoneyMonk is here to save your financial life! It's like having a smart monkey 🐒 managing your expenses and income - but way cooler and less messy! 

### ✨ Why MoneyMonk is Different:
- 🧢 - Real-time expense tracking 
- 🧠 - Smart income management
- Clean, modern UI that doesn't hurt your eyes
- 🔒 - Your data stays private!

  
## 🎯 Features That Hit Different

### 💸 Expense Tracking
- Add expenses faster than you spend money (which is saying something!)
- Categorize your spending habits 📊
- Visual charts because we love pretty graphs ✨

### 💰 Income Management  
- Track all your money sources (side hustles included!)
- Set financial goals that actually make sense
- See your progress without the math anxiety

### 📱 Dashboard That's Actually Useful
- Clean interface that doesn't overwhelm
- Real-time updates because waiting is not it

- **React.js** ⚛️ - Because vanilla JS is for boomers

### Backend (The Brain)

## 🚀 Quick Start (Let's Get This Bread!)

### Prerequisites
Make sure you have these installed :
- Node.js 
- MongoDB (Local or Atlas - your choice)
- Git (Obviously)

### Installation Steps

1. **Clone this masterpiece**
```bash
git clone https://github.com/Kumarikhushi712/MoneyMonk.git
cd MoneyMonk
```

2. **Backend Setup** 🔧
```bash
cd backend
npm install
# Create .env file with your secrets 
cp .env.example .env
npm start
```

3. **Frontend Setup** 
```bash
cd ../frontend  
npm install
npm start
```
